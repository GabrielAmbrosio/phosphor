# PHOSPHOR

**ЭЛТ-терминал для Windows.** Имитация люминофора с послесвечением и выгоранием, строчная развёртка, кривизна кинескопа, десять скинов, дополнительные рамки мониторов, загрузочная последовательность, синтезированные звуки и режим скорости модема. Запускает PowerShell или любую команду, например [Claude Code](https://claude.com/claude-code).

![Скин Green P1 с бежевой рамкой в стиле 80-х](docs/img/skin-green-p1.jpg)

PHOSPHOR — небольшое приложение на Electron: [xterm.js](https://xtermjs.org/) рисует терминал, [ConPTY](https://learn.microsoft.com/windows/console/creating-a-pseudoconsole-session) (через `@lydell/node-pty`) запускает оболочку, а WebGL-шейдер превращает каждый кадр в стеклянную трубку. Проект вдохновлён [cool-retro-term](https://github.com/Swordfish90/cool-retro-term), у которого нет версии для Windows.

## Скины

Каждый скин задаёт цвет люминофора и все эффекты и выбирает рамку монитора. Переключайте скины клавишей **F10** или **Alt+Shift+Влево/Вправо**.

| | |
|---|---|
| ![Atomic](docs/img/skin-atomic.jpg) **Atomic**: ретрофутуристичный зелёный, заметные строки развёртки, выгорание | ![Sepia](docs/img/skin-sepia.jpg) **Sepia**: тёплый, «бумажный», мягкие эффекты |
| ![Amber 80s](docs/img/skin-amber-80s.jpg) **Amber 80s**: классический янтарный монохром | ![Cool Cyan](docs/img/skin-cool-cyan.jpg) **Cool Cyan**: холодное голубое свечение |
| ![IBM Blue](docs/img/skin-ibm-blue.jpg) **IBM Blue** | ![White P4](docs/img/skin-white-p4.jpg) **White P4** с рамкой ретро-телевизора |

Также есть: **Green P1** (по умолчанию), **Claude** (оранжевый), **Color** (сохраняет цвета вашего терминала) и **Clean** (почти без эффектов).

## Возможности

- **Люминофор:** послесвечение (свет гаснет постепенно), выгорание (слабый «призрак» того, что долго оставалось на экране), свечение, мягкость, подсветка стекла, скруглённые углы и анимация включения.
- **Кинескоп:** кривизна, строчная развёртка, апертурная маска, виньетка, мерцание, горизонтальная нестабильность, полоса обновления и волна размагничивания при смене скина.
- **Рамки мониторов** (по желанию): Beige 80s, Black и Retro TV, нарисованные на CSS, со светодиодом питания.
- **Загрузочная последовательность** (по желанию): несколько строк в стиле BIOS. Любая клавиша пропускает её.
- **Звук** (по желанию, синтезируется, без аудиофайлов): щелчки клавиш, гул ЭЛТ и звук включения.
- **Скорость вывода:** ограничивает вывод терминала, как медленную последовательную линию (пресеты от 300 до 19200 бод). Если накопился большой объём текста, он выводится быстрее, так что отставания в минуты не бывает.
- **Режим Comfort:** убирает мерцание, дрожание, всплески шума и вспышки для долгих сессий.
- **Настройки производительности:** ограничение частоты кадров и качество рендера (см. ниже).
- Копирование и вставка (**Ctrl+C** копирует при выделенном тексте, **Ctrl+V** вставляет), буфер обмена OSC 52 для приложений, экспорт в PNG, полноэкранный режим.
- Все настройки сохраняются автоматически.

## Запуск

Требуются Windows 10/11 и [Node.js](https://nodejs.org/) 18 или новее.

```powershell
git clone https://github.com/GabrielAmbrosio/phosphor.git
cd phosphor
npm install
npm start
```

- `npm start` открывает PowerShell.
- `npm run claude` открывает Claude Code (подойдёт любая команда: `npx electron . <команда>`).
- Двойной щелчок по `phosphor.cmd` или `phosphor-claude.cmd` запускает то же самое без окна консоли.
- `--phosphor-cwd=C:\некая\папка` задаёт начальную папку.

### Сборка установщика

```powershell
npm run dist        # установщик NSIS и portable exe в dist/
npm run dist:dir    # распакованное приложение в dist/win-unpacked
```

Пока вы не добавите свой значок (`build/icon.ico`), приложение использует стандартный значок Electron.

## Управление

| Клавиша | Действие |
|---|---|
| **F10** | Панель настроек: скины, рамка, ползунки, звук, скорость |
| **F11** | Полноэкранный режим |
| **F12** | Сохранить экран ЭЛТ как PNG в папку «Изображения» |
| **Alt+Shift+Влево/Вправо** | Предыдущий / следующий скин |
| **Ctrl+C / Ctrl+V** | Копировать (при выделении) / вставить |
| Любая клавиша | Пропустить загрузочную последовательность |

## Производительность

Экран работает только тогда, когда это нужно:

- **Ограничение частоты кадров** (по умолчанию 30 к/с, 10 к/с, пока окно не в фокусе).
- Терминал копируется в текстуру GPU **только при изменении**; статичный экран без анимированных эффектов (например, скин Clean) пропускает почти все кадры.
- Проход **послесвечения** останавливается, когда «призрак» угас, а **выгорание** работает на 10 Гц и только когда включено.
- Шейдер делает **14 чтений текстуры** на пиксель.
- **Качество рендера** (100 / 75 / 50 %) обменивает чёткость на время GPU и память.

Измерено на Windows 11, Electron 33, окно 1100x720, терминал в простое, сумма по всем процессам Electron (`PHOSPHOR_STATS=1`; значения отличаются примерно на 15 % от запуска к запуску):

| Конфигурация | Отрисовано кадров в секунду | Память (все процессы) |
|---|---|---|
| Первая версия, без ограничения | около 100 | 550–740 МБ |
| По умолчанию, лимит 30 к/с | около 28 | около 520 МБ |
| Скин Clean (ничего не анимировано) | около 4 | около 490 МБ |
| Качество 50 %, окно не в фокусе | около 10 | около 440 МБ |

Около 270 МБ из этого — базовый расход Electron (процессы браузера, утилит и рендера); меняют эти настройки именно процесс GPU.

## Как это работает

1. xterm.js рисует терминал на 2D-канвасах, которые остаются невидимыми, но принимают ввод с клавиатуры и мыши.
2. Когда xterm сообщает о перерисовке, канвасы объединяются и загружаются как текстура WebGL.
3. Проход 1 смешивает новый кадр с предыдущим (послесвечение). Проход 2 хранит очень медленный «призрак» (выгорание). Проход 3 рисует экран: кривизну, свечение, строчную развёртку, маску, шум, виньетку и скруглённое стекло.
4. Рамка монитора — обычный CSS поверх.

Всё умещается в четырёх файлах: [`main.js`](main.js) (окно, pty), [`preload.js`](preload.js), [`renderer.js`](renderer.js) (терминал, шейдеры, панель) и [`index.html`](index.html).

## Тесты и скриншоты

- `npm run shots` пересоздаёт скриншоты в `docs/img/`, по одному окну на скин.
- Тестовый режим: `PHOSPHOR_SHOT=out.png` сохраняет скриншот окна и завершает работу; `PHOSPHOR_STATS=1` выводит память и CPU по процессам; `--phosphor-fps=1` пишет число отрисованных и пропущенных кадров.
- Если вы запускаете приложение из другой программы на Electron (например, из терминала VS Code), сначала очистите `ELECTRON_RUN_AS_NODE`; лаунчеры `.cmd` делают это сами.
